# 资源来源与许可文件索引

本目录随 Runtime 源码／资产增量提供，不会安装到游戏 payload。无需下载 Blender 作者附件即可查看以下来源和原始许可文本。所有引用文件均逐字复制并纳入包成员 SHA-256 校验。

- `cc0-hand/LICENSE.ASSETS.md`：MakeHuman 静态资产的原始 CC0 1.0 文本。
- `cc0-hand/LICENSE.md`：同一上游提交的原始总体许可说明，区分程序代码与静态资产；不是给本工程重新指定许可证。
- `cc0-hand/download_manifest.json`：实际取得的静态模型、骨架、权重与许可文本的固定提交、原始 URL、字节数和 SHA-256。记录范围为静态数据，不是下载或执行 MakeHuman 程序代码的声明。
- `original-room-source.md`：原扩展房间的程序建模来源说明。其“无第三方资产”描述只适用于该文档所述原房间组，不适用于后来使用 CC0 手部数据的人物精修。
- `pbr-source-manifest.json`：当前 `surface_finish_v2` 原创确定性程序 PBR 材质清单，含生成脚本、种子、物理尺度假设、通道约定及各贴图身份。它们不是摄影扫描、下载贴图包或运行时 AI 图片。

本补丁不修改原工程、保留的人物身体／服饰／动作或其他既有文件的许可。完整作者附件另含可编辑资产和生成来源；此目录不替代其技术说明，也不对原始许可文本作删改或重许可。
