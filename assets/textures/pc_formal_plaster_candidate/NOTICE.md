# Original analytic test material

These are original deterministic data textures authored for this project by `tests/fixtures/plaster_microfinish_candidate/generate_maps.py`. They are not a scan, photograph, downloaded asset, or AI-generated image. No third-party texture or captured material is incorporated.

The RGB8 map is linear OpenGL +Y tangent-space normal data derived from a dimensioned analytic periodic height; the L8 map is linear roughness. Both are actually 4096×4096. Parameters are restrained artistic physical-scale assumptions, not measured material properties. The exact source height, seed, hashes, provenance, units and generation metrics are recorded in `material_manifest.json` and the test fixture.

Test-only, opt-in. No new albedo, geometry displacement, production material edit, native visual acceptance, or performance benefit is implied.
