# Expansion provenance

All eleven GLB models and their editable Blender scenes were authored procedurally
for this PoolCore project with `build_expansion.py` in Blender 4.3.2. No external
models, texture packs, paid assets, fonts, or downloaded geometry were used.

The reference board was generated with OpenAI's built-in image generation tool
on 2026-10-22. It is visibly labelled AI ARCHITECTURAL REFERENCE / NOT RUNTIME.
It is not a game screenshot, a downloaded architectural photograph, or a runtime
texture. It is provided only to document the design reference for this modelling.

Runtime materials intentionally reuse existing PoolCore material-library roles.
The complete project's existing license/provenance is not changed by this pack.
The package introduces no third-party asset-license dependencies.
