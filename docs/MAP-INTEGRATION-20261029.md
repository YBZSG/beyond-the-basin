# 地图、主页与踩草更新

本地合入 `PoolCore-Complete-SOURCE` 的地图内容和 V5 高廊补丁。新增地图作为独立探索区，原六章主线的重新设计留到后续；不会在主线通关时自动接管出口或修改主线存档。

## 进入方式

启动后进入主页：左侧可以进入主线或继续当前场景，右侧可选择原有场景和 15 个新增地图。地图切换时显示加载界面，碰撞、水体及场景准备完成后才释放玩家操作；新增地图保留独立进度。主页的「设置」可调整镜头、水体、画质、声音及角色。

新增地图：青柠回廊、暮色运动场、雾中水庭、水族中庭、末班车站、天眼巨厅、云朵球海、悬手浅池、无尽交错楼梯、压顶水库、错尺长池、交错旱渠、倒悬浴场、空面水殿、浅水深井。它们保留素材包中的房间设施与探索流程，但不自动接入原主线。

原泳池吸收步道、入水台阶、座椅和设施布置；其他原有场景吸收 17 个更新后的模型，主线过场吸收座椅改动。V5 高廊补丁改造高廊和塔架的三处梯子、平台与栏杆；没有替换共享人物控制器。原泳池出生点调整到新步道上方。

室外草地通过人物落地接触压弯，离开后约 7 秒恢复。草叶是 GPU 实例化变形，而非每根草一个刚体；每次保留最多 8 个局部接触点。原有水体模拟、光追水面降噪、模拟相机和 YuE2 背景音乐继续保留。

## 检查范围

- 15 个地图的构建脚本和场景定义均可加载。
- RTX 5070 Laptop、1280×720、原生 RT、DLSS Balanced、NR 单层、帧生成关闭：实际进入青柠回廊、悬手浅池、浅水深井和暮色运动场；检查主页、设置、地图加载与人物落点。未逐个走完全地图，也没有手机测试。
- 高廊三处梯子通过当前人物控制器实际攀爬，到达的平台均检测到支撑。
- 踩草接触数据进入材质并随离开恢复；查看了实际草地画面。没有做长时间压力或帧率基准。
- 新草地着色器改为使用世界位置生成风和颜色差异，避免当前定制 RT 引擎在 `INSTANCE_CUSTOM` 上编译失败。
- 最终 PCK 1079 项逐项 MD5 校验通过。原包 536 项全部保留，24 项按本次地图和入口更新，其余 512 项字节不变；音乐与可选人物资源保持原包内容。用户 profile 在复制出的测试目录中测试，真实配置和存档未被修改。

源包中手部与新材质的来源记录随资源保留，汇总见 `CREDITS.md`。本地证据在工作区外层 `map-merge-20261029`；旧 PCK 回退文件是同目录的 `PoolCore.before.pck`。本次不涉及 GitHub 推送或发行包发布。
