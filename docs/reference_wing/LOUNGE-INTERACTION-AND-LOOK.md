# 球池互动与青绿柔光 · 本地更新 2026-10-26

## 使用

重启现有运行包。主菜单“镜头”选择 **青绿柔光 / POOLROOMS**：一键启用青绿色调、静态镜头色散、颗粒/暗角、加强的灯具高光与柔晕，以及交错水波。此预设不会套用 VHS 的全画面横向抖动。滤镜位于 HUD 下方，文字保持清晰。

水体菜单可分别开关“参考交错水波”和“参考镜头滤镜”，并调整起伏、方向、尺度、彩边、颗粒及暗角。镜头选“原始”关闭滤镜；水波仍可单独保留。启用后的选择会保存，重启时继续使用。此次安装没有改写你当前的画质配置或主线存档。

圆窗球池休息室的全部 3465 个球均可选择，9 个软垫也可搬动。看向近处物品：左键拖动，E 拿起/放下，按住右键蓄力后松开投掷，滚轮调距离。走近球堆会拨动附近小球。

## 实现范围

- 原静态球批次在运行时换为两个共享球网格的 MultiMesh；沿用作者的全部位置、半径和两种材质。最多 64 个小球进入刚体集合，9 个软垫沿用原网格和滚边，使用凸形碰撞。
- 未激活的球使用分格冻结碰撞体，给移动球和软垫提供支撑。休眠且远离玩家的球回到批次绘制，保留当前落点；不会把仍在飞行或手持的球强行回收。菜单暂停会冻结互动。
- 接入现有参考翼玩家的抓取/投掷系统，没有另造按键体系。主线第四章与独立参考翼共用同一房间接入。窗户、墙体及长凳保持建筑结构。
- 物件摆放变化仅在房间本次载入期间保留，未新增物件位置存档。主线交接物、角色、相机和游戏存档未替换。另一套 ithappy 人物仍未启用：缺少游泳动作且实际授权未确认。
- 参考水波由三组不同方向和波长的光学法线叠加，并修正倒影方向偏移，保留原求解器的涉水和脚步涟漪；这不是新增水面高度/浮力模拟，也不是真实水体光追。
- 加强的是预设内的亮部曝光感和灯光柔晕，保留房间原光照能量、场景曝光和绿色氛围。关掉滤镜即恢复原镜头。
