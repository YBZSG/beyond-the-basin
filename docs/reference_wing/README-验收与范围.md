# 五境参考场景：验收与范围

本轮在 Godot 专用分支 `351fcd6f8f2bb5fe21851482e2526dfa262ef406` 上制作独立的「五境参考场景」。不是替换原地图，也不修改 Web 项目。这是可供本机验证的源码/资产候选，不是画面已通过的成品；不能把 Blender 预览当作 Godot / NVIDIA 实机效果。

连续实际碰撞路线已覆盖五房间并返回阶厅上端，共318.17m（最终资产重测318.1665m，48段连续路线）。仅参考翼启用恢复接触台阶适配；原世界控制器保持不变。测试使用实际地形深度桩，不是图形/流体联合验收。

## 五个空间

1. **釉光阶厅**：干燥下行楼梯、斜扶墙、暗色植槽、小拱门、两排条灯。它不是另一间水池。墙砖低粗糙度，走路面更粗糙。
2. **暗柱水厅**：成对方柱、中轴矩形顶灯、暗侧廊；柱脚实际落到水下池底。
3. **青窗水廊**：狭长浅水道、左侧黑窗龛、右侧落地禁行标志；出口通过封闭折廊连接。
4. **粉阶八角池**：八角盆地、三层下水台阶、叠级顶棚、暖色左门与暗右门。
5. **圆窗球池休息室**：粉色室内、浅蓝/白球池、抬高长座与软垫、圆窗。球为静态装填，不是水面或数千颗动态刚体。

所有房间在 Blender 中完整搭建，GLB 与简化实体碰撞由同一生成源导出。Godot 负责连接、原水体、角色与交互，不在运行时随机拼装这些建筑。

## 材质与可选效果

- 阶厅/柱厅采用10 cm方砖、约1.8 mm灰缝。青廊为15 cm缎面砖，粉池为20 cm缎面砖，按参考图的可见比例推定而非照片实测。对应窄缝随比例为2.7/3.6 mm。釉面与缎面都非金属，单砖微小稳定弯曲与边缘法线分离，数据图按线性读入；第5图的低粗糙亮釉不会套到全部墙顶。
- 参考细浪与镜头滤镜独立开关，默认均关闭。细浪只是原水面法线上的有界光学叠加，不代替原高度场、风纹、涉水或水花求解器。
- 关闭滤镜恢复原相机效果；参考滤镜不处理 HUD。彩边、颗粒、暗角可分别调节，不是通过模糊掩盖材质。
- 新八角水面采用匹配真实盆地的裁剪网格与静态深度边界。原水体求解公式、原场景地形缓存与用户的大水波不变。

## 查找与游玩

主页的出生场景选择「五境参考场景」，保留现有种子后进入。初始位置是釉光阶厅上端；下行至小拱门进入暗柱水厅，继续通向青窗水廊，侧向连接粉阶八角池与圆窗球池休息室，最终形成可步行返回的闭环。菜单目的地列表也可选择五个房间。原有随机地图和主厅选项仍在，不会被替换。

新参考翼暂不写入旧版探索手记，菜单会明确说明；旧地图记录保留，回退不会因新世界记录使旧版整本手记拒读。出生选择、种子、独立滤镜/波浪设置仍正常保存。

## 检查与限制

云端可运行官方 Godot 4.6.3 的无显示资源/物理/设置测试及 Blender 4.3.2 CPU 预览；没有可用的目标 NVIDIA / 定制 Godot4.8 图形环境。用户已选择自行在本机测试最终画面。因此本包不包含重编译引擎、不代表 NR/RT 效果验收，也不提供 Windows FPS 结论。

菜单「复制诊断」也会包含本次独立滤镜/细浪设置、实际参考灯数量与水波应用状态，便于将设置值和本机截图对应。诊断只在本地复制，不自动上传。

实际构图截图应采用 `UI_REVIEW.md` 中每个房间的固定相机与对应宽高比。先关闭参考滤镜与 NR 检查釉面，再分别启用，避免把滤镜变化误认成材质改善。`material_evidence/CPU_CROP_REVIEW.md` 记录了同机位、同灯具的粗糙度/面形变对照及剩余亮边噪声。

原水体的入射遮挡仍有原实现的粗 AABB 限制，光子焦散只使用其前两个有效灯源。八角厅最终只启用4个有实际灯具支撑的光源，8条旧凹槽光带关闭；左门暖灯在真实连廊内向外投射。光子入射仍按原点光近似，不具备新Spot灯的锥角。这里没有人为忽略遮挡或补假的发光焦散图案。

Android 本轮暂停，GitHub 没有自动推送。参考照片用于设计对照，不作为项目贴图打包。新建筑、植物、球池与新材质图为本项目程序化原创，已有第三方资产许可保持原样。

## 最终候选的已知差异

- 第5图的特殊釉面只用于阶厅的垂直瓷砖面：0.075非金属面粗糙度、0.30mm等效局部冠形法线并带±15%稳定逐砖变化；干地保持0.26，不是镜面地板。Blender对照能看到按砖重新分布的亮斑，但原生RT/NR下反射清晰度、降噪与运动稳定性尚未验证。
- 青廊已改为独立青色缎面砖和左上方竖直灯条，作者预览仍比参考暗。粉池左门采用真实腔内暖光，暖色外溢仍弱于参考。最终亮度不能从Blender瓦数等同推算为定制引擎结果。
- 已审计五个最终导出，原48处外露共面重叠已去除；当前取样机位/路线未检出新的可见共面冲突，但仍记录63处埋入、外侧或未确认视角的接触。不能将有限取样称为所有角度绝无接缝。
