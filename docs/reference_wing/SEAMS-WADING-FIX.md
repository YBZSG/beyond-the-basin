# 接缝与淌水修复（2026-10-25，本地）

## 改动

- 参考翼的结构 BOX 以碰撞契约判定实际接触面和接触边。部分 L 形墙只在边上相接，4 mm 倒角后出现贯通空隙；新增合并的遮挡背衬，封住这些位置和墙顶接合处。门窗、布局、碰撞、瓷砖 UV 保留。每个房间增加一个合并网格，不增加灯和粒子。
- 背衬遵守原水面镜像相机的裁切规则，避免水下背衬出现在水面倒影里。
- 淌水继续按实际移动距离注入连续动量，保留宽推波/尾波。脚步改为身体两侧交替的小波纹；移除每步额外在前方生成的大幅正负波团、重复细波和浪尖粒子调用。人物模型和动画片段没有删除。
- 原水面和参考水面共用浮沫外观：稀疏、随流移动的斑块，远处细节过滤；亮度随局部环境变化，低浓度时消散，不再形成发亮的灰白涂抹。未增加粒子或纹理贴图。

## 实际检查范围

- RTX 5070 Laptop GPU、当前定制引擎、RT 1 spp / 3 bounces、关闭 NR。暗柱水厅及青窗水廊的墙角/墙顶同机位对照；亮缝消除。没有进行全地图逐角度验收。
- 实际 CharacterBody3D、角色模型、生产水求解器与材质运行了走动、停步。约 4 m 路程产生 7 次脚步事件，停步后事件数保持 7；采样中连续推水前方约有 4–8 cm 水位起伏。定向控制器检查 8 项通过，含连续尾波、小脚步波、无额外前方冲击、相机高度保持。
- 浮沫对照用同一位置的较强测试扰动，比较旧/新着色器；新版本去除了明显的白色团块。截图和日志在工作区 `evidence/seams-wading-20261025/`。
- 退出仍有引擎既存的 `OpTypeForwardPointer` 提示和 7 个 Texture RID 清理警告。本记录不代表零警告、NR/插帧验收或性能跑分。
