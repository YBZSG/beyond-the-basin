# 新翼资源来源与分发范围

本次新增的五套建筑、植物叶片、球池装填、座椅/软垫、标志和灯具均由本项目的 Blender 生成脚本制作。对应完整、可编辑的 `.blend` 和同源 GLB 一起交付，不依赖付费建模插件或外部商业模型包。

新瓷砖底色、粗糙度/遮蔽、接缝坡度和法线图由 `tools/materials/reference_wing/` 中的确定性材质程序生成。它们不是扫描材质或照片推导的完整光谱测量，也不是由 AI 图片自动声称得来的真实 PBR。色彩与物理尺度是针对用户参考照片的设计选择，不是对照片中真实建筑的尺寸/反射率测定。

用户提供的五张图片仅作为构图、空间及材质方向参考，没有被用作墙面贴图，也不随更新包分发。本次没有提取 POOLS 游戏地图、贴图或其他商业游戏资产，没有购买付费资源。源文件中的参考文件名仅说明设计对应关系，不是运行时输入依赖。

原项目、已有第三方素材及其许可证不被本更新替换、重授权或删除。原水体实现、NVIDIA/NR/RT 引擎集成及相应来源说明仍由原项目保留。本次更新不是引擎或 SDK 的再分发。

## 实际交付资源层次

- `assets/models/reference_wing/`：五套实际运行的完整 GLB、同源几何/碰撞/水域/灯光/相机 JSON 与新资源导入配置。
- `assets/materials/reference_wing/`：成套程序化材质图、生成参数及 SHA-256 清单、明确的数据图导入配置。
- `tools/blender/reference_wing/`：五套编辑源、正式构建及几何检查脚本；编辑源目录中的 `.gdignore` 防止 Godot 自动启动 Blender 导入第二套模型。
- `tools/materials/reference_wing/`：材质图与 Blender/Godot 一致参数的生成工具。
- `scripts/reference_wing/`、`shaders/reference_wing/`：仅新翼的连接、材质、光源、独立可选效果和原水体适配。

正式资源和已否决的试验有明确分界。未通过的材质强度试验、临时光照模型、输出渲染和缓存不是运行时依赖，不应手动覆盖到项目中。

所有预览必须保留来源标注：CPU Cycles 建模/构图预览不是 Godot 画面；Godot 4.6 无显示物理/资源测试不是用户定制 4.8 / NVIDIA 图形验收。最终本机画面验证由用户使用其现有引擎完成。
