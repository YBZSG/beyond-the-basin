# 参考翼釉面瓷砖（2026-10-25，本地）

按用户提供的 Blender 阶厅图调整材质质感，忽略图中的采样噪点。目标是光滑陶瓷、清楚的灯影、细凹缝和逐砖轻微起伏。原图作为材质参考，不代表 Godot 的运行结果。

## 改动

- 通用釉面粗糙度从 0.075 降到 0.055；原 satin 材质改为 0.085–0.09，干面为 0.14，砖缝仍为 0.82。
- 启用已有的局部圆润砖面法线，将形状强度设为 1.25。默认 10 cm 砖距的中心鼓度约 0.375 mm，保留原有倒角与凹缝。
- 在既有房间调色后，砖面底色乘 0.68，砖缝乘 0.85；反射光仍保持原光源颜色，不叠加表面噪点或新贴图。
- 仅修改参考翼材质家族的 `reference_materials.gd` 和 `reference_glaze_surface.gdshaderinc`。沿用现有光栅/原生 RT 材质配对，不改变光照、曝光或引擎。

## 检查与证据

使用当前 Godot 定制引擎、RTX 5070 Laptop GPU、原生 RT 1 spp / 3 bounces、NR 关闭，对阶厅同机位截图。砖面灯影更明确，具有逐砖变化，近景保留细凹缝。截图来自实际 Godot 渲染，不是 Blender 预览，也不声称两者逐像素一致。

证据位于外层 `evidence/glazed-tiles-20261025/`，包含修改前、源码运行及最终 PCK 运行截图和日志。最终包 489 个资源逐文件 MD5 校验通过；接缝、水波与浮沫检查范围见 `SEAMS-WADING-FIX.md`。没有进行全地图逐角度检查、NR/插帧验收或性能跑分。退出仍有既存的 `OpTypeForwardPointer` 提示和 Texture RID 清理警告。
