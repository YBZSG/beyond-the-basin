## 进入游戏

解压 Play ZIP。把官方 Godot 4.6 的 Windows EXE 拖到 `Launch-PoolCore.cmd`，或放在同目录后双击 CMD。CMD 接受带空格/中文的完整路径，保留版本、启动退出码及引擎日志；不下载、不安装、不自动上传任何信息。实际验证环境为 Godot 4.6.3 Standard / Forward+；Windows 目标 GPU 尚未验收。

首次未保存设置时默认“原仓库场景”。Esc 菜单的“出生地 / STARTING WORLD”可选“原仓库场景 / ORIGINAL”或“重做主池厅 / FORMAL HALL”，点击“在此出生”应用并保存选择。两个世界都保留；正式主厅仍有连续拱廊和侧池。切换时菜单保留，角色与浮动物体等待真实水深场，不会先掉进未准备区域。

WASD 移动，鼠标视角，Shift 跑，Space 跳跃，E 或左键拾取，右键按住蓄力/松开投掷，Esc 菜单，H 隐藏界面，G 诊断。拿起物品时滚轮向上推远、向下拉近，范围 0.75–3 m，与原浏览器回调的方向一致。
