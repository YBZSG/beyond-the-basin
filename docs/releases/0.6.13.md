# PoolCore PC 0.6.13 — 2026-10-26

Windows x64 安装包：`PoolCore-PC-0.6.13-Setup.exe`。此版本仍是开发中的公开测试版本，Android APK 没有同步更新。

## 变化

- 六章探索主线、交接物与独立检查点存档，参考翼房间和球池／软垫互动。
- 青绿柔光镜头、交错水波、L 键手电筒；保留已调整的湿润瓷砖和场景氛围。
- 修正光追灯罩、局部漏光与纹理接缝；淌水按实际位移产生波纹，减少浮沫和重复拍水观感。
- 暂停菜单顶部增加人物选择，原探索者与 ithappy 人物可切换并保存偏好。新人物不新增游泳动作，原池不新增深水区。
- 新 Windows 安装器，首次启动建立配置，升级保留存档；附带定制编辑器。README 与源码根目录 CMD 给出另一台电脑的运行步骤。

## 检查范围

人物双向切换、持物状态保留、实际移动与显示已做定向检查；原生 RT 下检查菜单和模型。先前主线房间切换、球池互动、水波／滤镜和手电已有对应运行证据。测试显卡为 RTX 5070 Laptop，当前引擎为打补丁的 Godot 4.8-dev。

发布过程另检查干净源码导入、安装包文件一致性、首次启动和升级存档保留，结果随 GitHub Release 附件提供。没有完整主线通关、全地图、全部动作、其他显卡或手机验收。

仍有既存 OpTypeForwardPointer 与退出 Texture RID 诊断。帧生成果冻感没有宣称修复，首次默认关闭。NR 需要支持的硬件，和帧生成互斥；本次发布检查没有重做 NR/FG 性能验收。

## 人物资产与许可证

原探索者随 Git 源码提供。ithappy 原始 GLB/贴图不作为独立素材公开到源码仓库，安装版在游戏资源包中使用该模型。来源及提供者记录见 `source_provenance/ithappy/`。这些记录不对第三方素材另行授予许可证；各第三方组件许可随安装包保留。
