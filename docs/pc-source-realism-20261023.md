# 原泳池 PC 写实材质更新

本轮以原泳池画质为优先，保留既有几何、人物、水体模拟、反射、折射和动态焦散。版本为 `0.6.5-pc-realism-20261023`，基于 `9d009ff9c5a41ccf873a00ad5dc553a9b7a0338b` 的本地改动。

## 改动

- PC Forward+ 的原瓷砖角色改用已有 4K PBR 数据：250 mm 砖距、4.5 mm 接缝、圆润边缘、独立砖面/砂浆粗糙度。使用世界米制投影，保持原房间尺度与色板。
- 新增 512² 周期釉面数据，含 6 μm RMS 微起伏和粗糙度变化。它是可复现的程序材质，不是实景扫描或照片；生成脚本与来源记录随源码保留。
- 潮湿带约束在现有 0.32 m 水位附近。湿砂浆变暗，薄水膜的反射率和干釉面分开处理；远处法线细节渐隐并加入高光抗闪烁。
- 原泳池灯具的颜色适度中和，功率转换系数从 0.07 调至 0.115；数量、位置、相对功率和闪烁保留。曝光仍为 1.25，没有用提高曝光替代照明。
- PC 距离雾密度乘 0.65；主相机、平面反射与立方体捕获共用最终密度，探索衰败仍参与计算。原有距离雾渲染顺序不变，不启用与它冲突的 SSR。
- Android、iOS、`--mobile-preview` 和非 Forward+ 继续选择原材质与雾参数。此次未重建/发布 APK，未作手机实机验证。

这次没有加入硬件光追或新体素追踪器，仍使用项目已有 SDFGI。距离完整照片级场景仍有空间，特别是几何细节、道具材质和原日光束的表现。

## 实际 GPU 对比

RTX 5070 Laptop、Godot 4.7、Vulkan/Forward+、1600×900、Ultra。旧 PCK 与新 PCK 使用同一官方完整 Godot 主程序、相同用户配置和相机，独立 APPDATA。每视角预热后取 120 帧；水面保持推进，道具在静态对比中冻结。实时时序仍可能令水纹/闪烁有差异，不将逐像素差异当成全部来自材质。

| 视角 | 旧平均 ms | 新平均 ms | 旧 P95 ms | 新 P95 ms |
| --- | ---: | ---: | ---: | ---: |
| 原泳池大厅 | 27.51 | 25.95 | 32.31 | 32.33 |
| 瓷砖近景 | 28.37 | 26.77 | 29.62 | 27.63 |
| 贴水视角 | 27.24 | 25.81 | 28.20 | 26.66 |
| 相邻漂浮物厅 | 25.89 | 24.01 | 26.61 | 24.73 |
| 高拱门日光厅 | 24.65 | 23.01 | 25.42 | 23.94 |

这是短场景观察，不是长时间/全地图稳定帧率保证。大厅 P95 没有改善。主视口 GPU 分项约从 10.27–11.78 ms 降至 9.56–11.12 ms；该计时不含所有水体计算与反射视口，不能当成整帧 GPU 时间。未降低 8×MSAA、TAA、2048 平面反射、8192 阴影图或水体 Ultra 档。

证据位于 `output/photoreal/baseline`、`output/photoreal/final`；可复用 `tools/qa/capture_source_finish.gd`。正式 release EXE 启动及人物/行走/持物检查记录位于 `output/photoreal/acceptance`。

已有的退出时 7 个 Texture RID 泄漏警告仍存在。没有进行全世界长时间游玩或其他显卡验证。
