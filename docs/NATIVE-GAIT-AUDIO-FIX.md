# 地面脚步声修复与验收记录

## 已定位的原因

原移植版把 `player.global_position.y < 0.25` 当成在水里。普通地砖上的脚底高度约为 0，因此会同时叠加 `step_swish` 和 `step_stir` 两条水声，再加上瓷砖脚步，全部经过泳池混响。这是代码层面已经复现的干湿误判，不是推测素材丢失。

17 个源 OGG 与原仓库提交 `66a4543602d9e774db07c2da12ce1d40d522532c` 的文件逐字节相同。源项目没有使用实时合成脚步，而是播放这些录音。原文件完整保留；本次衍生文件仅使用这些现有录音，没有引入外部游戏声音或付费素材。

## 实际改动

- 音频在角色移动之后，按真实水平位移、有效水区、水深、脚底/水面位置、垂直速度和攀爬状态判断水声。撞墙、站立、腾空、攀梯、传送都不会被输入速度或固定高度误认成涉水。
- 地面每步仍由真实角色的 interaction 信号触发，保留原来的距离节拍：走路每 0.62 米、跑步每 1.05 米；没有修改水体力学或原来的水面耦合公式。
- 两个走路录音继续左右交替，跑步使用独立较重录音。裁去 42–73 毫秒的噪声前导、抑制尖锐高频和极端瞬态、加上短首尾包络。新的 PCM 不做有损导入。
- 地面脚步由独立的单音源和 Footsteps 总线播放，不再占用 24 个空间水声通道。音高随机范围从 ±6% 收窄到 ±1.5%，线性增益从旧移植版走路 0.50 / 跑步 0.55 调为 0.30 / 0.34。
- 脚步混响单独限制为 wet 0.06–0.095，保留完整直达声；不再沿用水声 wet 约 0.21–0.26 的长尾。房间高度仍轻微影响空间感。
- 相同物理帧/过密重复信号不能叠加脚步。菜单、失焦触发的暂停、静音会停止一次性声音、清空涉水目标并静音效果尾声；恢复时必须重新发生有效移动。
- 水声两个循环使用原 source audio.ts 的 200 毫秒首尾拼接方式。水声不是按每一个脚步重复触发；五个衍生 PCM 的导入与循环长度已验证。
- 切换原场景/正式主厅、重建玩家时重新绑定音频观察对象，不保留旧身体或旧水域的状态。

- 既有 `tests/source_coupling_test.gd`：16,057 项比较、0 失败，最大绝对差约 0.00000247。本次没有改动水体计算。
- Godot 4.6.3 headless；脚步专项测试退出无错误/泄漏警告。固定帧率测试的真实音频线程预留 200 毫秒清理时间。

## 试听与限制

`native-gait-audition.wav` 是 15 秒离线干声试听：0–4 秒为旧脚步素材/旧增益，5–9 秒为处理后的走路，10–14 秒为处理后的跑步。间隔为留白。它不模拟旧版错误叠加的水声，也不包含 Godot 总线混响，不是游戏实录。

此环境没有完成真人耳机/扬声器听测，不能声称“已经听过、听起来更自然”。已经验证的是误触发原因、音源图/信号/节拍和实际 PCM 波形。最终主观听感仍需在用户目标设备试听；本文件和试听片段如实区分了这一点。

## 复现

```sh
python tests/native_gait_audio_assets.py
# 需要重建音频时追加 --build；需要 ffmpeg、NumPy、SciPy。
HOME=/tmp/native-gait-home XDG_DATA_HOME=/tmp/native-gait-data \
XDG_CACHE_HOME=/tmp/native-gait-cache XDG_CONFIG_HOME=/tmp/native-gait-config \
godot --headless --path . --fixed-fps 120 --script tests/native_gait_audio_test.gd
```
