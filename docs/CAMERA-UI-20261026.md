# 模拟摄像机与提示界面

本地源码与可玩包的相机界面更新，2026-10-26。

- Esc → 右侧「相机与探索」→ 镜头选择「模拟摄像机 / 青绿柔光」。F 可循环切换五种镜头，包含这个模式。
- 同一区域直接调整灯光光晕、边缘彩边、颗粒、暗角。镜头选择和强度自动保存；保留原有设置，不强制改写玩家的镜头偏好。
- 「大波纹 / 交错水面」在主菜单和水体页首屏均可开关，两处同步。选择镜头不会再重置水波；关闭后仍保留脚步、涉水、物体交互与原有细风纹。
- 正常探索只显示克制的取景角标、REC、右下角本机日期与时间，以及原有准星/蓄力反馈。REC 是模拟摄像机装饰，不实际录制文件。
- 按住 Tab 查看房间、操作、主线任务及到访文字，松开隐藏；切出窗口清除按住状态。H 隐藏取景界面。菜单中 Tab 继续切换键盘焦点。
- 主菜单采用暗绿、暖白配色，提升相机与水面入口；沿用既有滚动布局和焦点导航。主线读铭牌、过场、错误/恢复界面仍按原流程显示。

镜头使用原有单次全屏后处理，加强亮部扩散、暖色光晕、边缘色散与低对比固定扫描纹理。没有增加历史帧依赖或全画面抖动；场景光照、曝光、水体模拟和光栅折射降噪实现保持原样。旧 VHS 模式自身的原有抖动仍保留，新模拟摄像机模式不使用它。
