# PoolCore PC 扩展版：开始探索

这是功能性的四房间与骨骼角色扩展 PC 预览版，不是照片级写实场景，也不是对参考图的逐像素复刻。新增房间、随机地图与带骨骼角色已接入；仍是持续开发中的作品。本轮没有新的 Android 安装包。

## 先打开哪个文件？

- 如果收到多个分块 ZIP：把同一版本全部分块解压到同一新文件夹，运行 Rebuild-PC-Package.cmd（游戏）或 Rebuild-Source-Project.cmd（源码）；也可用同名 Python 脚本。重建会校验 SHA-256。分块不能单独运行，也不能混用其他版本。
- 解压重建后的完整游戏 ZIP，运行 Launch-PoolCore.cmd。游戏资源文件名称为 PoolCore-PC-Expansion-20261022.pck，请保留它与 native 文件夹的相对位置。
- 若包内附带 PoolCore-PC-Expansion-20261022.exe，它与同名 PCK 配套。若没有这个完整 EXE，则不是独立运行包：需要官方 Godot 4.6.3 Standard Windows x64 完整主 EXE，将它拖到 Launch-PoolCore.cmd。不要选择小型 _console.exe 包装器。启动器不会下载引擎或修改系统安全策略。
- 可编辑源工程不是游戏安装包。Windows 将完整 Godot 主 EXE 拖到 Prepare-Editor.cmd，等待首次导入，再运行项目。Blender 源文件、模型生成脚本和参考图均随核心源工程保留。

本次新增 4 个房间模块与 7 个可复用道具模型：长凳、淋浴器、线性排水槽、扶手、门廊、导向牌、设备门。原有源版水体系统、反射/焦散和交互继续保留，不以静态贴图代替动态水体。

## 选择要探索的世界

进入菜单，在“出生地 / STARTING WORLD”选择后点击“在此出生”：

- 原仓库场景 / ORIGINAL：保留原版随机房间，新用户默认从这里开始。
- 重做主池厅 / FORMAL HALL：独立的主池厅及相连的精修空间，不是扩展随机地图。
- 扩展随机地图 / EXPANDED：加入淋浴更衣间、低拱静浴、天窗泳廊和设备过渡厅，并与原版房间按种子混合生成。

输入种子后点击“重建种子世界”，可重新生成当前模式的世界；同版本、同模式、同种子应得到相同布局。重建会重置本次场景与探索位置，并不是保存当前游玩进度。水体准备期间请等“继续探索”按钮恢复可用。

开发源的确定性/连通性 CPU 检查覆盖 128 个种子、56,448 个坐标；另有门洞/碰撞净空、双向真实控制器路线与混合流式加载检查。这个测试范围不等于穷尽全部种子，也不是最终 PCK 的画面验收。

“显示角色身体 / PLAYER BODY”可开关第一人称身体显示。原始世界、主池厅和扩展世界的选择互相独立于该开关。

## 常用操作

- WASD 移动，鼠标转动视角；Shift 奔跑，Space 跳跃。
- 左键抓取/拖动物件，E 拿起或放下；持物时按住右键蓄力、松开投掷，滚轮调距离。以准星附近提示为准。
- 对准梯子按 E 攀爬，W / S 上下，E 松开。
- Esc 打开/关闭菜单；R 返回当前模式起点并放下持物。
- F 切换镜头滤镜；H 隐藏界面；G 显示诊断；F11 切换全屏。
- V 切换原生间接光，C 切换焦散；也可在菜单调整，诊断对比时请记录设置。

## 新角色能做到什么？

这是原创程序化建模的角色，不是扫描级写实人物。实际模型采用 42 根骨骼和真实蒙皮权重，包含站立、行走、奔跑、持物、涉水、游泳、攀爬 7 个动作。动作只负责外观，移动、碰撞和水中行为仍由原控制器负责。角色目前只有两张原创布料颜色贴图，没有制作角色法线贴图；这与建筑陶瓷已有的颜色/法线/粗糙度贴图是两回事。

持物目前是上半身姿势混合，不会根据不同物体形状自动贴合手指，也没有物体感知抓握 IK。没有单独的跳跃动画片段；跳跃控制可用，但不代表所有动作都已有专用动画。足部没有地形自适应运行时 IK；攀梯动作也不等于双手会准确抓住每一级梯横档。肩部形变、接触精度和动作自然度仍可继续打磨。

## 画质与验证说明

- 新用户默认画质仍是 High；已保存的个人设置会被读取。本轮原生诊断截图使用 Medium、960 × 540、MSAA 2×、GI 关闭，不能当成默认 High 效果，也不是你电脑上的帧率测试。
- 当前开发源版本已完成建筑/身体观察、四段实际控制器路线、真实入水、完整当前反射与焦散、水中身体以及原有小黄鸭正常抓取/放下检查。最终 PCK 与 Windows 的实际验证状态，以同包 PC-EXPANSION-STATUS.json 中分别绑定实际文件的记录为准；不能把开发源测试直接算作 PCK 通过。
- 更细水面与 GPU 立方体反射仍是默认关闭、显式开启的实验，不代表已完成验收。局部湿膜只是近似的局部薄膜，已展示的视觉收益很小，不足以成为新默认，仅可通过 --pc-local-wet-finish 主动开启，默认关闭。普通启动不启用这些实验。
- Launch-Experimental-Mainhall.cmd 只用于可选主厅烘焙预览，不是完整游戏的新默认灯光。其他房间并不因此具有同等间接照明。
- 最终交付范围请查看同包 PC-EXPANSION-STATUS.json 与 PC-STATIC-PACKAGE-AUDIT.json；尚未生成这些报告的文件，只能作为开发检查点使用。

参考图是建模设计依据，不是实机截图。若启动失败，请保留启动器生成的报告与错误信息，不要删除旧版本或关闭系统保护来尝试修复。
