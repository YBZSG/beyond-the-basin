# 室内泳池水体增量升级

## 原实现与取舍

原实现已是变水深浅水方程：交错网格存储高度与水平速度，GPU 双缓冲积分，384² 异步读回驱动物体浮力与水流。它已有封闭池壁、台阶水深、柱子绕流、玩家动量源、物体尾流、Schlick Fresnel、平面反射，以及通过 Snell 折射和光子投影计算的池底/池壁焦散。本次保留这些求解与交互路径。

原来的表面细节是三组快速正弦法线，随浅水活动量一起出现；没有独立细波传播、屏幕空间折射、深度吸收和质量分档。焦散固定使用 2048² 目标和较密的光子网格。

## 现在的四层

| 层 | 实现与默认行为 |
| --- | --- |
| 浅水物理 | 保留交错网格压力、连续性、动量平流；按网格、水深上限、速度上限约束 CFL；默认阻尼从 0.45 降至 0.28，黏性扩散从 0.004 降至 0.0015；池壁封闭面反射并在邻近单元损失部分能量。源波长限制在至少四个单元。 |
| 交互细波 | 独立 48 m GPU 高度/速度场，120 Hz、有阻尼的波动传播；脚步、碰撞、入水和水滴同时驱动它；大入水附加多个微小波源。环境扰动默认仅约 0.024 mm，不驱动物体。 |
| 微表面 | 两组不同尺度和方向的解析微法线，缓慢移动；距离与像素覆盖共同衰减；浮动原点偏移保持相位连续。没有滚动法线贴图输入。 |
| 光学 | IOR 1.333 的 Schlick；独立线性 HDR 场景颜色和深度用于折射与 Beer–Lambert 吸收；复用平面反射；同一个浅水/细波梯度影响折射、反射和光子焦散。 |

主模拟继续供物体使用。细波纹只贡献表面高度和梯度，几何部分按顶点间距过滤，避免把无法解析的细波变成网格起伏。场景不使用 TAA，因此没有新增历史重投影或 SSR 抖动。动态焦散逐帧更新；所有动态层关闭且物理平静时才缓存。

水下光子接收高度会读取台阶水深。屏幕折射对前景深度进行拒绝检查并限制偏移，减轻物体边缘漏色。泡沫沿用现有剧烈入水的少量气泡与水滴，池壁只加微弱水线。

## 质量与调试

暂停菜单 → 水面设置 → 水体质量；默认 High。所有滑块自动保存在本机，并校验非法或越界参数。

| 档位 | 浅水网格 | 表面分段 | 细波网格 | 焦散图 | 平面反射 | 折射尺寸 |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| Low | 384² | 96² | 关闭 | 关闭 | 256² | 关闭，常规透明混合 |
| Medium | 384² | 192² | 384² | 768²，仅池底 | 384² | 绘制尺寸的 65% |
| High | 768² | 384² | 768² | 1024²，池底与池壁 | 768² | 绘制尺寸的 80% |
| Ultra | 1152² | 512² | 1152² | 2048²，池底与池壁 | 1536² | 完整绘制尺寸 |

切换主模拟分辨率会重采样现有波场并保留物体读回；短暂的细波细节场会重新初始化。切回较低档位会释放高档目标和网格。

Water Debug Panel 提供高度、速度、模拟法线、细波纹、最终法线、水深、Fresnel、折射、焦散和反射视图，以及各层独立开关。模拟开关控制可见表面，底层物理继续运行，避免切换调试层改变浮力。关闭面板恢复完整水面；质量档位决定哪些视觉层可用。

## 验证方式

- `npm run typecheck`、`npm run lint`、`npm test`、`npm run build`。
- `tests/pool-water-gpu.mjs`：真实 GPU 上的传播、池壁、台阶、柱子、原点移动、同时扰动、动量尾流、物体随流和长期耗散。
- `tests/pool-water-layers-gpu.mjs`：三种网格在最大波速/黏性下稳定、波场重采样、池壁部分耗散、独立细波传播/衰减/隔墙阻断、模拟驱动焦散。
- Edge 运行过程与截图位于 `output/water-opt/`；测试用 `?qa=1` 接口仅在开发版开放。

## 实现边界

细波场覆盖当前房间附近的 48 m，边缘逐渐减弱；浅水物理覆盖 96 m。焦散仍复用当前房间的投影图集和两盏主灯，没有扩展为全场景多次散射。反射为现有平面反射，没有引入 SSR。折射是带深度拒绝的屏幕近似，无法恢复画面外的被遮挡内容。质量切换可能触发一次资源分配和 shader 编译。
