# 本地人物切换（2026-10-26）

重启本地游戏，按 Esc，右侧「02 探索设置」顶部的「角色选择」可选择：

- 原版探索者 / ORIGINAL：保留既有人物、自然手与补充动作。
- ithappy 创意角色 / CREATIVE：使用朋友完整源码包提供的人物与独立 44 骨骼适配。

默认原版；选择立即生效，并保存到运行 profile 内独立的 `character.cfg`。切换仅替换视觉身体，当前位置、镜头、持物、地图和主线状态保持。低头可查看身体，抓取物品时可查看手部。F 仍切换镜头滤镜，并非第三人称视角。

新人物使用原素材的站立、走路、跑步、攀爬及跳跃动作；淌水使用走路循环配合已有步幅处理。按用户要求不新增游泳动作，也不增加深水区。原版人物可随时切回。新人物不套用原版衣物织纹覆盖层。

素材缺失或骨骼载入不通过时保留当前人物；下次启动选中的素材不可用则回退原版。角色身体开关仍可隐藏/显示两套人物。
