## 怎么玩

- 使用 `Launch-PoolCore-Campaign.cmd`，或在 Esc 菜单选择「主线 · 继续旅程」。
- 六章从收集物品改为操作设备：配电、水压、导流、回声、通风、采光。设备会留在场景中。
- 靠近并看向设备，按 **E** 操作，按 **Q** 阅读铭牌。阅读时计时暂停，Q / Esc 返回。
- 完成本章机关后，返回本层入口终端进入下一章。
- 超出稳定窗口后逐渐出现绿色侵蚀与局部灯光变化。暂停菜单的「应急修复」保留机关进度；「舒缓模式」停止计时和侵蚀。
- 「重试本章机关」需连续点击确认，会重置当前章机关，保留前章进度。人物选择仍在右侧探索设置，L 手电、F 滤镜照常使用。
