在已核验的 v2 私有源码检查点上继续打磨。仍是 **Godot 源码工程，不是已通过目标 Windows GPU 验收的发行包**。自定义 NR 引擎、光追和真实 GPU 水体需匹配原运行环境；官方 Godot 无窗口测试不能替代。

## 怎么玩

- 菜单选择“主线 · 继续旅程”，或以 `--campaign` 启动。
- WASD/鼠标沿用原控制；靠近并看向设备，按 **E** 操作。物件不再被收走，阀轮、开关、镜面、压力指针会留下可见状态。
- HUD 给环境提示而不列物品坐标；查看设备上的机械刻线、管线图和图案获得可解的线索；靠近看向设备按 **Q** 可主动阅读中文版刻牌，阅读期间暂停计时，Q/Esc合上。错误操作可恢复，不靠隐藏随机密码或精确反应时机。
- 入口终端在本层系统稳定后解锁。可自由拨动值班铃、开合柜门；这些小互动不影响通关。
- 各房首次进入有对应的短暂空间提示、设备检视灯/罩动作及温和声音标记；不夺走玩家镜头。声音跟随现有音效/环境声开关。

## 时间、侵蚀与无障碍

每章有宽裕的稳定窗口。超时后，侵蚀在约两分钟有效游玩时间内缓慢增强：偏绿、变暗、部分灯具短暂熄灭。不会频闪、移除地板、吞掉已完成机关或强制死亡。

**暂停菜单、失焦、加载、过场、设备尚未安全放好时不计时。** 离线时间不计；长卡顿帧限制收费。门口应急复位台和暂停菜单都能修复侵蚀，保留机关进度。狭窄楼梯平台可由通道终端兼任应急复位，避免堆放多个柜体堵路。

- **舒缓模式**：不计压力时间、不产生新侵蚀；机关照常工作。
- **减弱动态效果**：新侵蚀不做局部熄灯，过场镜头更克制。它不宣称关闭所有原地图已有灯光动画。
- **重试本章机关**：再次点击确认，只重置本章，不清除前章。
- 若设备找不到安全落点，会暂停计时并提供“重建本章场景（保留机关进度）”，不静默留下缺失出口。

初始时间预算仍需真人逐章试玩校准，不把程序通过当作难度已完美。

## 存档与切换

沿用原存档文件名并升级内部格式至 revision 2。旧版已通关/已准备好的章节不会被撤销；部分旧收集物保留，当前新机关从安全状态开始，每件旧物增加30秒宽限。

操作、检查点、每十秒有效游玩、暂停和退出会保存；保留原来的指纹冲突检测、临时文件验证、备份和原子替换。损坏原档不会被覆盖。只读恢复状态可明确点击另存恢复副本，原档保留。

六种过场都是有封闭边界的独立镜头场景，**在全黑遮挡中更换世界，不声称整个工程是无缝巨型地图**。只有下一章世界、物理落点/身体净空和水体就绪后才提交进度。准备超时或取消会回到旧章；如果回程也没准备好，保持暂停并提供重建/退出，不让玩家进入错误世界。

## 保留资产与验证边界

已有模型、贴图、角色私有许可文件保持私有；旧钥匙/阀柄等模型保留以兼容原检查点，但新主线不靠收集它们通关。未推送、未公开发布。

CPU 测试覆盖六种真实解法、错误输入、重复操作、JSON 中途恢复、v1迁移、损坏存档、计时暂停、修复/重试、异步取消/超时、六种过场、28个实际设备、通道/修复柜、局部站位与遮挡、检查点身体净空。部分跨房路线还通过实际控制器或采样图检查；这些不等于全章真人走通或目标 GPU 视觉验收。

没有通过关闭水体、全局光照或反射掩盖问题，也不宣称消除了所有截图中的黑/绿屏原因。目标 Windows 自定义引擎的水体、NR/RT、帧率、全部角色视角和逐章体验仍需实机验收。详细接口见 `STATE-API.md`；各专用测试说明记录它们的准确范围。

## 字体可读性

新主线UI、到访字幕和设备铭牌显式使用随工程附带的 **PoolCore Campaign SC** 字体，是本地 Noto Sans CJK SC 的重命名子集（约0.4MB）；完整 SIL OFL 1.1 许可及来源/哈希见 `assets/fonts/campaign/`。覆盖所有当前源码/目录中文和ASCII，避免依赖目标电脑的中文字体回退。Q检视窗提供20像素中文等价说明；世界内小字的最终距离/显示器可读性仍需实机验收。
