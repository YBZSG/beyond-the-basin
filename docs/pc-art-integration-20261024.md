# PC 场景与自然手部整合 0.6.12

版本：`0.6.12-pc-art-integration-20261024`。基于 `36b85dd`，继续使用已验证的 NVIDIA Godot 4.8-dev 引擎及四份引擎补丁。

## 吸纳内容

- 合入朋友 Runtime Source Patch 的 73 个新增运行文件和 3 处接入点：四类扩展房间 GLB、20 张 PBR 贴图、自然手部角色及动作衔接代码。
- 新角色保留 54 骨架和 14 个动作，手部数据来自 MakeHuman CC0 静态资产。网格约 56,501 三角形，旧角色约 65,703；三角形减少不能单独证明帧率提升。身体、相机可见层、持物及水体控制仍沿用现有实现。
- 地砖、瓷砖、抹灰、金属等材质为原创确定性程序生成 PBR，不是摄影扫描。来源与许可见 `source_provenance/art-pass-20261024/`。
- 原泳池仍为默认入口，保持约 1.04 m 平底浅水。新房间在菜单的扩展场景中使用；没有重新加入已撤回的深水区。
- 保留旧版和移动端选择策略；`--legacy-art-pass` 可以恢复旧场景及人物资产。无效手部绑定合同会回退到原角色。

五份 ZIP 的 CRC、清单及目标基线已检查。运行补丁 SHA-256 为 `30820ae06e7883694c1cbc3bc609322609d0a28f003e6c34d0079d62fcd422d3`。作者工程、生成脚本和 Blender 源文件保存在独立审阅目录，没有覆盖运行工程。六页对照 PDF 已阅读；其中 Godot 4.6.3 软件 Vulkan / Blender 结果属于朋友的证据，不能替代下面的本机检查。

## 氛围与反射修复

保留“越探索越崩坏”的原设计。现有程序房间按距起点的最大坐标距离分为 0–3 级：0–1 格正常，2–3 格轻度，4–6 格中度，7 格及以后重度；灯光和场景变化继续使用原机制。用户认可的绿色、阴湿氛围作为后续深层美术方向保留，本次没有添加新的绿色滤镜或修改崩坏曲线。四类维护设施房间仍按原目录定义使用 `corrupt=0`。

整合后实际 GPU 检查发现，正常房间也可能整片饱和绿。贴图原图、导入图和最小材质场景正常；隐藏原生反射探针或在场景就绪后重新捕获可消除异常。问题定位到原生缓存反射路径，尚未证明具体的引擎内部根因。

现在扩展场景流送完成后，等待地形和水体光学准备就绪，再触发一次原生探针重新捕获，随后保持 `UPDATE_ONCE`。延迟任务使用弱引用，并检查场景及流送版本，避免访问已卸载的房间。没有使用常驻逐帧反射捕获。准备期间探针会暂时隐藏；长时间探索的切换开销尚未单独量化。

## 本机验证

Windows、RTX 5070 Laptop、1920×1080；独立 APPDATA，GPU 检查串行执行。朋友的完整水体与人物组合已在本机实际运行。

- 7 项 CPU 合同通过：默认选择、旧资产、移动预览、禁用动作衔接、无效合同回退、相机净距和路线移动。
- 路线测试使用新房间碰撞与真实控制器，在 Jolt 120 Hz 下完成 32 项、262.5 模拟秒。水深为测试夹具，不是完整 SWE 水体性能测试。
- 30 / 60 / 120 Hz 游泳与停泳相机检查通过。采样身体到眼睛最小距离分别为 0.16794 / 0.16632 / 0.16520 m；不是对全部连续蒙皮三角形的数学保证。
- 最终 PCK 在普通渲染与原泳池硬件光追下通过游泳、停泳低头、回到淌水和持物检查。新手合同有效，54 骨、30 指骨、24 个受保护身体骨骼的绑定符合约定。最终持物目标误差约 0.58 mm。已检查关键截图。
- 四类新房间的 GLB 均实际加载；每房间 961 个地面射线采样，共 3,844 点无缺口。逐房间等待当前流送、地形、水体光学和反射恢复后才截图，25 个原生探针可见且保持单次更新。正常地板区域的饱和绿色检测比例均为 0，已查看四张实际截图。
- 完整水体淌水位移 1.47 m，浮沫场峰值约 0.129；已检查实际画面。扩展地图 RT 自动回退，返回原池恢复 RT 请求。最终日志无脚本或渲染错误。
- 正式 EXE 实际运行通过：1080p、Ultra、DLSS Balanced、原池硬件光追开启、帧生成关闭；预热 120 帧后测量 360 帧，平均 21.57 ms（约 46.36 FPS），P95 22.93 ms。固定镜头、冻结漂浮物，不能代表完整游玩或其他硬件；未做同条件旧版 A/B，不宣称性能提升。已检查实际截图，证据位于 `output/dlss/art-release-final-0612/`。

证据：`output/art-integration/cpu-summary.json`、`output/art-integration/clearance.json`、`output/art-pass/route-contracts/movement-candidate.json`、`output/dlss/art-floor-settled/`、`output/dlss/art-camera-final-0612/`。发布 ZIP 附带验证报告与截图。较早失败诊断不作为通过依据。
